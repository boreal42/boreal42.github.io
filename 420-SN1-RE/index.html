Politique sur l'IA générative

Les assistants d'IA font partie du travail en sciences. Ce cours t'apprend les habiletés qui te permettront de juger si leur code est correct.

La règle

Permis : demander à l'IA d'expliquer une notion, un message d'erreur ou un exemple du chapitre.

Non permis : lui demander d'écrire le code d'un exercice, d'un labo ou d'une évaluation à ta place.

Pourquoi

Les évaluations mesurent ta capacité à planifier un programme, à en faire la trace et à valider ses résultats. Une IA peut écrire du code, mais elle ne peut pas développer ces habiletés à ta place.

Pendant les évaluations

Les évaluations se font sur le site du cours, qui n'a aucun assistant d'IA intégré, en laboratoire et sous supervision.

Un code que tu ne peux pas expliquer n'est pas ton code. L'enseignant peut te demander d'expliquer n'importe quelle ligne que tu as remise.

Résoudre un problème

Planifier un programme (ch. 1)

  1. Lis l'énoncé et note les grandeurs, avec leurs unités.
  2. Intrants : les données que le programme reçoit.
  3. Extrant : le résultat attendu, et son unité.
  4. Traitements : les étapes, en français ou en pseudocode, dans l'ordre.
  5. Jeu d'essais : des cas dont tu connais la réponse, calculés à la main avant de coder.

Bâtir un jeu d'essais (ch. 3 et 4)

  1. Une condition : au moins un cas par branche, plus un cas exactement sur chaque borne (> ou >=?).
  2. Une boucle : un cas où elle ne tourne aucune fois, un où elle tourne une fois, et un où elle tourne plusieurs fois.
  3. Une liste : la liste vide, une liste d'un seul élément, des valeurs négatives, des doublons.
  4. Note pour chaque cas le résultat attendu, puis compare avec le résultat obtenu.

Faire une trace d'exécution (ch. 4)

  1. Fais un tableau avec une colonne par variable, plus une colonne « Affichage ».
  2. Exécute le programme à la main, une ligne à la fois.
  3. À chaque affectation, écris la nouvelle valeur dans une nouvelle ligne du tableau.
  4. Compare ensuite ton tableau avec l'exécution réelle : ajoute des print() et exécute.
a = 3          # a=3
b = a * 2      # a=3  b=6
a = a + b      # a=9  b=6
print(a, b)    # affiche : 9 6

Écrire et tester une fonction (ch. 6 et 7)

  1. Choisis un nom qui dit ce que la fonction calcule, et ses paramètres (les intrants).
  2. Écris le corps, puis return le résultat. Pas de print() ni d'input() dans une fonction de calcul.
  3. Sous la fonction, écris un assert par cas du jeu d'essais. Pour un réel, compare avec une tolérance.
  4. Exécute : aucun message signifie que tous les tests passent.
def energie_cinetique(m, v):
    return 0.5 * m * v ** 2

assert energie_cinetique(2, 3) == 9
assert abs(energie_cinetique(0.1, 1.5) - 0.1125) < 0.000001

Lire un message d'erreur (ch. 2)

  1. Lis la dernière ligne du message : elle donne le type d'erreur.
  2. Repère la ligne de ton code indiquée dans le message.
  3. Cherche le type d'erreur dans l'aide-mémoire.
  4. Corrige une seule chose, puis exécute de nouveau.

Déboguer en cinq étapes (ch. 10)

  1. Reproduire : trouve un cas précis qui donne un mauvais résultat, et note le résultat attendu.
  2. Lire : s'il y a un message, lis sa dernière ligne, puis la ligne de ton code en cause.
  3. Localiser : ajoute des print(f"{i=} {total=}") ou fais la trace pour trouver la première ligne où une valeur devient fausse.
  4. Corriger une seule chose, à partir d'une hypothèse, puis réexécuter.
  5. Retester tout le jeu d'essais, puis enlever les print() de débogage.

Travailler avec des données

Lire un fichier CSV (ch. 9)

  1. Ouvre le fichier avec with open(...) : il sera fermé automatiquement.
  2. Saute la ligne d'en-tête avec next(lecteur).
  3. Pour chaque ligne, convertis chaque colonne utile avec float() ou int() : le fichier ne contient que du texte.
  4. Vérifie le résultat : le nombre de lignes lues, la première et la dernière valeur.
import csv

temps = []
valeurs = []
with open("donnees.csv") as fichier:
    lecteur = csv.reader(fichier)
    next(lecteur)
    for ligne in lecteur:
        temps.append(float(ligne[0]))
        valeurs.append(float(ligne[1]))
print(len(temps), temps[0], valeurs[-1])

Nettoyer des données honnêtement (ch. 13)

  1. Garde les données brutes intactes : construis une nouvelle liste nettoyée.
  2. Fixe les règles de rejet avant de regarder les résultats (valeur manquante, code d'erreur, plage physique) et écris-les dans le code.
  3. Compte les mesures rejetées, par raison, et rapporte-les.
  4. N'invente jamais de valeur pour remplacer une mesure manquante.

Faire un graphique scientifique (ch. 11)

  2. Un titre, et chaque axe avec sa grandeur et son unité : "Temps (s)".
  3. Une étiquette label= par courbe, puis plt.legend().
  4. Regarde le graphique : la forme et l'ordre de grandeur ont-ils du sens?

Valider un résultat (ch. 2, 10 et 12)

  1. Unités : le résultat a-t-il la bonne unité?
  2. Ordre de grandeur : est-il plausible? Une vitesse de 3000 m/s pour une balle lancée, une température de −300 °C : non.
  3. Cas connu : le programme redonne-t-il une réponse connue (sans frottement, avec des valeurs simples)?
  4. Convergence (méthodes numériques) : diminue le pas ou la tolérance; le résultat doit presque ne plus changer.

Méthodes numériques (ch. 12)

def bissection(f, a, b, tolerance):      # racine de f entre a et b
    while b - a > tolerance:             # f(a) et f(b) de signes contraires!
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
    return (a + b) / 2

aire = 0                                 # trapèzes : aire sous des mesures

    aire = aire + (y[i] + y[i + 1]) / 2 * (x[i + 1] - x[i])

for i in range(round(duree / dt)):       # Euler : dv/dt = taux
