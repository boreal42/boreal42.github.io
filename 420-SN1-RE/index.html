Programmer pour résoudre des problèmes scientifiques

Dans ce cours, Python devient un instrument de laboratoire. Tu apprends à planifier un programme, à l'écrire et à vérifier que ses résultats ont du sens, sur des problèmes de physique, de chimie, de biologie et de mathématiques.

Éthique numérique

Politique sur l'IA générative

Les assistants d'IA font partie du travail en sciences. Ce cours t'apprend les habiletés qui te permettront de juger si leur code est correct.

La règle

Permis : demander à l'IA d'expliquer une notion, un message d'erreur ou un exemple du chapitre.

Non permis : lui demander d'écrire le code d'un exercice, d'un labo ou d'une évaluation à ta place.

Pourquoi

Les évaluations mesurent ta capacité à planifier un programme, à en faire la trace et à valider ses résultats. Une IA peut écrire du code, mais elle ne peut pas développer ces habiletés à ta place.

Pendant les évaluations

Les évaluations se font sur le site du cours, qui n'a aucun assistant d'IA intégré, en laboratoire et sous supervision.

Un code que tu ne peux pas expliquer n'est pas ton code. L'enseignant peut te demander d'expliquer n'importe quelle ligne que tu as remise.

Marches à suivre

Recettes

Les gestes qui reviennent chaque semaine, en quelques étapes.

Où est sauvegardé mon travail?

  1. Ton code et tes fiches sont sauvegardés automatiquement, à chaque modification.
  2. La sauvegarde est dans ce navigateur, sur cet appareil. Un autre ordinateur, un autre navigateur ou une navigation privée ne la voient pas.
  3. Si tu effaces l'historique de ton navigateur, la sauvegarde disparaît : télécharge ton rapport régulièrement.

Remettre ton travail sur LÉA

  1. Au bas de la page du chapitre, écris ton nom dans la section Remise sur LÉA.
  2. Clique sur Télécharger mon rapport. Tu obtiens un fichier .py qui contient ton code, tes fiches et le résultat de chaque vérification.
  3. Dans LÉA, ouvre le travail du chapitre et dépose ce fichier.

Continuer sur un autre appareil

  1. Sur le premier appareil, télécharge ton rapport.
  2. Sur le second, ouvre la page du même chapitre et clique sur Importer un rapport, au bas de la page.
  3. Choisis ton fichier : ton code, tes fiches et tes réussites reviennent.

Lire un message d'erreur

  1. Lis la dernière ligne du message : elle donne le type d'erreur.
  2. Repère la ligne de ton code indiquée par la flèche.
  3. Cherche le type d'erreur dans l'aide-mémoire.
  4. Corrige une seule chose, puis exécute de nouveau.

Faire une trace d'exécution

  1. Fais un tableau avec une colonne par variable, plus une colonne « Affichage ».
  2. Exécute le programme à la main, une ligne à la fois.
  3. À chaque affectation, écris la nouvelle valeur dans une nouvelle ligne du tableau.
  4. Compare ensuite ton tableau avec l'exécution réelle : ajoute des print() et exécute.
a = 3          # a=3
b = a * 2      # a=3  b=6
a = a + b      # a=9  b=6
print(a, b)    # affiche : 9 6
