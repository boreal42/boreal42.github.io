Problème d'ouverture

Ton cahier de laboratoire de chimie donne des températures en degrés Celsius. Les tables thermodynamiques que tu consultes sont en kelvins, et l'article américain que tu cites parle en degrés Fahrenheit. Convertir trois valeurs à la main, ça va. Convertir 400 mesures, non.

Un programme fait ce travail sans se fatiguer et sans se tromper, à condition que tu lui aies dit exactement quoi faire. C'est le sujet de tout le cours.

Les priorités sont celles des mathématiques : parenthèses, puissances, multiplications et divisions, puis additions et soustractions.

Piège : le point décimal

Python utilise le point comme séparateur décimal. On écrit 9.81, jamais 9,81. La virgule a un autre sens en Python, et l'erreur passe souvent inaperçue.

La démarche : planifier, coder, vérifier

C'est la méthode du cours, du premier labo jusqu'à l'épreuve finale. On ne code jamais avant d'avoir planifié.

Les erreurs sont normales

Python s'arrête et affiche un message quand il ne comprend pas une instruction. Lis le message : sa dernière ligne dit quel type d'erreur s'est produit, et le numéro de ligne dit où.

Exécute ce code : il contient une erreur de syntaxe volontaire. Corrige-la directement dans le bloc.

Message Cause habituelle
SyntaxError Python ne peut pas lire l'instruction : virgule, parenthèse ou guillemet manquant
NameError un nom est utilisé avant d'avoir été créé, ou il est mal écrit
ZeroDivisionError une division par zéro

Piège : l'ordre d'exécution

Python exécute les instructions de haut en bas. Si tu utilises une variable avant la ligne qui la crée, tu obtiens un NameError, même si la variable est créée plus bas.

L'IA générative dans ce cours

Les assistants d'IA font partie du travail en sciences. Dans ce cours, la règle est simple :

  • Permis : demander à l'IA d'expliquer une notion, un message d'erreur ou un exemple.
  • Non permis : lui demander d'écrire le code d'un exercice, d'un labo ou d'une évaluation à ta place.

La raison est pratique : les évaluations mesurent ta capacité à planifier, à faire la trace et à vérifier un programme. Ce sont exactement les habiletés qui te permettront plus tard de juger si le code d'une IA est correct. Voir la politique complète.
