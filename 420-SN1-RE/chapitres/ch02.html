Les variables

Une variable est un nom associé à une valeur. Le signe = est une affectation : la valeur à droite est calculée, puis rangée dans le nom à gauche.

Comme = veut dire « reçoit », l'instruction suivante est valide, même si elle est fausse en mathématiques : Python calcule compteur + 1, puis range le résultat dans compteur.

Bien nommer ses variables

Règle Valide Invalide
Lettres, chiffres et _ seulement vitesse_initiale vitesse-initiale
Ne commence pas par un chiffre t2 2t
Les majuscules comptent masse et Masse sont deux variables différentes

Dans ce cours, on écrit les noms en minuscules, avec des _ entre les mots, et on indique l'unité en commentaire. En sciences, une valeur sans unité ne veut rien dire.

Une valeur qui ne change jamais, comme g = 9.81 m/s², est une constante. Par convention, on écrit son nom en majuscules : G = 9.81.

Les types de données

Chaque valeur a un type. La fonction type() le révèle.

Type Ce qu'il représente Exemples
int nombre entier 3, -12, 0
float nombre réel 9.81, -0.5, 6.022e23
str texte (chaîne de caractères) "H2O", 'pH'
bool vrai ou faux True, False

Deux observations :

  • "9.81" est du texte, pas un nombre. Les guillemets font toute la différence.
  • 6.022e23 est la notation scientifique de Python : 6.022 × 10²³.

Convertir d'un type à l'autre

Fonction Convertit en Exemple Résultat
int() entier (tronque, n'arrondit pas) int(7.9) 7
float() réel float("9.81") 9.81
str() texte str(25) "25"

Les expressions

Une expression combine des valeurs, des variables et des opérateurs. Python la calcule en suivant les priorités mathématiques.

Deux opérateurs servent souvent à découper des quantités :

  • // donne le quotient entier : 125 // 60 vaut 2;
  • % donne le reste : 125 % 60 vaut 5.

Ensemble, ils convertissent 125 secondes en 2 min 5 s :

Deux fonctions intégrées très utiles : round(x, n) arrondit x à n décimales, et abs(x) donne la valeur absolue.

Piège : la division donne toujours un réel

10 / 2 vaut 5.0, pas 5. Ce n'est pas une erreur, c'est le comportement normal de Python : l'opérateur / produit toujours un float.

Le module math

Python n'a pas de racine carrée ni de sinus « de base ». Ces fonctions sont rangées dans le module math, qu'il faut importer une fois.

Piège majeur : les angles sont en radians

math.sin(30) ne donne pas 0.5 : Python interprète 30 comme 30 radians. Il faut d'abord convertir les degrés avec math.radians(). Et attention : math.log() est le logarithme naturel (ln), pas le log en base 10.

Tu obtiens 0.49999999999999994 au lieu de 0.5. C'est la précision limitée des nombres réels. On arrondit à l'affichage, jamais en cours de calcul.

Lire et afficher

input() lit toujours du texte

La fonction input() affiche une question et attend que l'utilisateur tape une réponse. Elle retourne toujours une chaîne, même si l'utilisateur tape un nombre. Pour calculer, il faut convertir :

masse = float(input("Masse (kg) : "))

Si l'utilisateur tape 2,5, float() échoue avec une ValueError : en Python, le séparateur décimal est le point.

Les f-strings

Une f-string commence par la lettre f et insère des valeurs entre accolades. Après un :, on précise le format d'affichage.

Format Effet {19.62:…} donne
.2f 2 décimales 19.62
.1f 1 décimale 19.6
.0f aucune décimale 20
.2e notation scientifique, 2 décimales 1.96e+01

Exemple complet : l'énergie mécanique

Planifier

Question Réponse
Intrants masse m (kg), vitesse v (m/s), hauteur h (m)
Extrants énergies cinétique, potentielle et mécanique (J)
Traitements Ec = ½ m v², Ep = m g h, Em = Ec + Ep, avec g = 9.81 m/s²

Jeu d'essais, calculé à la main avant de coder :

m (kg) v (m/s) h (m) Em attendue (J) Pourquoi ce cas
0.5 3 2 12.06 le problème d'ouverture
1 0 0 0 objet immobile au sol
2 1 0 1 énergie cinétique seule
1 0 1 9.81 énergie potentielle seule

Coder

Vérifier

Remplace les intrants par chaque ligne du jeu d'essais et compare.

Remarque l'écriture 0.5 * masse * vitesse ** 2 : grâce aux priorités, seule la vitesse est au carré. Écrire (0.5 * masse * vitesse) ** 2 donnerait un résultat faux, sans aucun message d'erreur.

Python n'avertit jamais d'une erreur de logique

Un programme peut s'exécuter sans erreur et donner un résultat faux. Seul ton jeu d'essais, préparé à l'avance, peut le détecter. C'est pour cette raison qu'on le construit avant de coder.

Trois erreurs à reconnaître

Erreur Exemple Cause
TypeError "Masse : " + 5 opération impossible entre deux types (texte + nombre)
ValueError float("2,5") conversion impossible : la valeur n'a pas le bon format
NameError print(Masse) la variable n'existe pas (ici, à cause de la majuscule)

Pièges fréquents

  • Écrire 9,81 au lieu de 9.81 : Python crée deux valeurs séparées, sans message d'erreur immédiat.
  • Oublier que input() retourne du texte.
  • Donner des degrés à math.sin() ou math.cos().
  • Confondre math.log() (ln) et math.log10().
  • Arrondir en cours de calcul plutôt qu'à l'affichage.
